![Status](https://img.shields.io/badge/status-stable-success)
![License](https://img.shields.io/badge/license-GPLv3-blue)

RandomResolution is a lightweight **Windows console application** written in **C++** that randomly changes your screen resolution from all resolutions supported by your display 🖥️.

---

## ✨ Features

🎯 Automatically detects supported screen resolutions  
🎰 Roulette-style random selection  
🖥️ Native Windows API resolution switching  
⚡ Fast and lightweight  
🧩 No external dependencies  

---

## 🛠️ How It Works

1️⃣ Scans all supported display resolutions  
2️⃣ Asks the user whether to start  
3️⃣ Cycles through resolutions with a spinning effect  
4️⃣ Randomly selects one resolution  
5️⃣ Changes the system resolution  
6️⃣ Displays the final result  

---

## ▶️ Usage

▶️ Run the program  
⌨️ Press `Y` to start  
🎰 Watch the roulette spin  
🖥️ Screen resolution changes automatically  

⚠️ **Warning**
Changing resolution may cause brief flickering or temporary black screens
